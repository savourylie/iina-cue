Cue for IINA · Technical Preview

Local AI subtitles. Uses Gemma 4 E2B, or a larger Gemma 4 model you download under Advanced in the Cue sidebar, with Qwen forced alignment; your video and captions stay on this Mac.

Manual activation and original-language captions are the defaults. Languages, subtitle size, the background box and pausing live in the Cue sidebar; the Plugin → Cue menu offers the same language choices.

Credits

Gemma 4 E2B, and the optional E4B and 12B (Google, Apache 2.0); Qwen3-ForcedAligner (Qwen team, Apache 2.0; MLX conversion by mlx-community). The license texts are in ~/Library/Application Support/Cue/runtime/licenses.

Development setup

This development build is set up in Terminal, from the Cue project folder. Click a command to select it.

  1. Prepare the environment: scripts/setup-dev
  2. Review the model sources, terms and roughly 3.56 GB download: scripts/setup-models
  3. If you agree, download the models: scripts/setup-models --accept-download
  4. Quit and reopen IINA.

Permissions: read selected videos and write local captions, run a local helper, connect only to 127.0.0.1, and show status. No microphone, screen recording, cloud service, or telemetry.
